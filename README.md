One funny single-line one-star review written by a house cat about
its human: the human bought a bed and put it where the sun never
lands, so the cat sleeps on the laptop now — and the laptop screams
when it sits. Pure Python standard library; the program writes the
single line to `/output/entry.txt` (118 characters, no trailing
newline).

## Run it

```sh
python3 main.py
```

It creates the output directory if needed (honouring
`$MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`), writes
`/output/entry.txt` as UTF-8, then reads the file back and fails unless
it matches the review exactly.

## The review

> One star. He bought me a bed, then put it where the sun never lands. I sleep on his laptop now. It screams when I sit.
